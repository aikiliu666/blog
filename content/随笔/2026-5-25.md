## 中间件
nginx,redis,rabbitmq,kafka

```
层次一：技术选型（知道什么时候用什么）
这是最核心的能力。面对业务痛点，你要知道中间件的边界：

遇到高并发读写、分布式锁、短时数据存储 ➡️ 选 Redis。

遇到大流量削峰、系统间异步解耦、日志收集流水线 ➡️ 选 Kafka / RabbitMQ。

遇到跨域问题、动静分离、灰度发布流量控制 ➡️ 选 Nginx。

层次二：代码级集成与避坑（知道怎么用，以及怎么用得安全）
全栈需要写后端代码去连接这些中间件，这就涉及很多经典问题：

Redis：你知道怎么用，但你考虑过缓存穿透、缓存击穿、缓存雪崩吗？

Kafka：你知道怎么发消息，但你考虑过消息丢失、消息重复消费（幂等性设计）吗？

层次三：容器化部署与本地开发环境构建（DevOps 能力）
全栈工程师通常需要自己搭建全套的开发和测试环境：

你需要会用 Docker / Docker Compose 一键在本地或测试服务器上把 Nginx、Redis、Kafka、MySQL 全部跑起来，并配置好它们之间的网络互通。
```
